## [0.1.0] - 2026-10-27

### Added
- Initial public preview
- Google Fonts family resolution
- Google Fonts specimen URL support
- Direct remote TTF and OTF loading
- HTTPS-only font transport
- Download size validation
- TrueType and OpenType signature validation
- Runtime Core Text registration
- Persistent disk caching
- SHA-256 cache integrity verification
- Atomic cache writes
- Concurrent request deduplication
- SwiftUI `googleFont` modifier
- SwiftUI `remoteFont` modifier
- UIKit `UIFont` creation
- Dynamic Type scaling
- Variable-font weight-axis support
- Font preloading
- Structured `FontKitError` errors
- Initial unit tests
